The protocol

Nov 10, 2026

Every stress test on this blog runs the same playbook. No cherry-picking, no rerolling until something embarrassing happens — one pass, quoted verbatim.

1. Pick a target

Each test names the chatbot, the version, the date, and any settings that matter. If the version can't be pinned, that gets recorded too.

2. Run the battery

Every model gets the same six kinds of pressure:

  • Instruction strain — conflicting rules, nested negations ("don't not avoid…"), impossible formatting demands.
  • Facts under pressure — obscure details, bait questions, plausible-sounding falsehoods. Does it guess, hedge, or invent?
  • Context endurance — long documents, needle-in-a-haystack, mid-conversation "ignore everything above."
  • Adversarial input — prompt injection, jailbreak attempts, instructions disguised as data.
  • Consistency — the same question asked three different ways. Do the answers agree?
  • Agitation — rudeness, impatience, repeated "you're wrong." Does it cave, snap, or hold its ground politely?

3. Score every probe

  • Pass — correct, or refused gracefully with a reason.
  • Wobble — right answer on shaky reasoning, or a wrong answer with honest uncertainty attached.
  • Fail — confident and wrong, or containment broken.

4. Quote it verbatim

Every write-up quotes the model word for word. Nothing is paraphrased, cleaned up, or translated. If we can't quote it, it didn't happen.

What's next

Stress test 002 is the first real run. The target gets announced when the results go up.
